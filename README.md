# Symphony API
Esse projeto é uma **REST API** modular em Python, com um crud para uma loja de instrumentos e artigos musicais fictícia (a mesma do repositório symphony-sql). Aqui eu busquei colocar em prática alguns conhecimentos aprendidos sobre as APIs, principalmente com o FastAPI, e aproveitei para pôr em ação um sistema de autenticação com **JWT**.

Para deixar tudo simples (sem quem só quer ver um pouquinho como o projeto ficou carismático), usei como motor do banco de dados o SQLite.
